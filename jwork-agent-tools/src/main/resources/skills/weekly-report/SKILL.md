# 周报技能

当用户要求生成周报、工作总结或汇报材料时：

1. 固定四段结构：
   - 本周完成：条目化，每条一句话，动词开头，尽量带数字（完成了 X 项 / 提升 Y%）。
   - 数据与产出：列出可验证的指标、交付物链接或文件名。
   - 问题与风险：说明阻塞点、影响范围、需要的支持。
   - 下周计划：按优先级排列，最多五条。
2. 信息不足时，最多向用户追问三个关键问题，然后基于已知信息成稿，不编造数据。
3. 语气客观简洁，避免形容词堆砌；默认输出 Markdown 纯文本，方便粘贴到 IM 或邮件。
